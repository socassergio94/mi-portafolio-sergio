## Cómo usar

1. Descomprime la carpeta.
2. Abre en VS Code y en la terminal del proyecto ejecuta:
```bash
npm install
npm run dev
```
3. Abre http://localhost:4321

## Estructura
- src/pages - páginas
- src/components - componentes reutilizables (ProjectCard, SkillBar, SeoHead)
- src/layouts - BaseLayout con <slot />
- src/styles - style.css
- public - imágenes y favicon
